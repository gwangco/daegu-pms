2. 보유 기간

데모 환경은 개발 PC 의 MySQL 데이터베이스에 저장하므로 서버를 다시 시작해도 입력한 정보가 남습니다. 데이터베이스를 다시 만들면 데모 데이터만 있는 처음 상태로 돌아갑니다. 실제 운영이라면 사업 종료 후 관련 법령과 기관 기록관리 기준에 따른 기간 동안 보관한 뒤 파기합니다.

3. 안전성 확보 조치

  • 비밀번호는 BCrypt 단방향 해시로만 저장합니다.
  • 연락처와 이메일은 국가 표준 블록암호 ARIA(전자정부 표준프레임워크 암호화 서비스)로 암호화해 저장하고, 관리자 화면에는 일부를 가려서 보여 줍니다.
  • 평가위원 화면에는 신청 기업의 사업자등록번호를 일부 가려서 보여 줍니다.
  • 비밀번호를 5회 연속 틀리면 계정을 30분 동안 잠그고, 로그인·로그아웃 기록(일시, 결과, 접속 IP)을 남깁니다.
  • 역할(관리자·담당자·평가위원·기업)별로 메뉴와 데이터 접근을 제한하고, 다른 기업의 신청서·정산·첨부파일 접근을 서버에서 차단합니다.
  • 첨부파일은 웹에서 직접 열 수 없는 위치에 임의의 이름으로 저장하고, 내려받을 때마다 권한을 다시 확인합니다.
  • 업무 로그에 입력 내용과 SQL 바인딩 값을 남기지 않습니다.
  • 데이터베이스 계정을 나눠, 화면 요청을 처리하는 계정은 조회·등록·수정·삭제만 하고 테이블 구조는 바꿀 수 없습니다.

4. 문의

데모 시스템이므로 개인정보 보호책임자와 고충 처리 창구는 두지 않습니다. 실제 개인정보를 입력하지 마세요.
